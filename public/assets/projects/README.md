# Project Screenshots Directory

Place your project screenshots here:
- `pixel-arena.png`
- `kathavani.png`
- `gyan-ai.png`

Then update the `screenshot` property in `src/data/projects.js`:
```javascript
screenshot: "/assets/projects/pixel-arena.png",
```

You can also drop screenshots interactively right on the website using the "Load Screenshot" button in each project preview!
